# Instagram 粉絲追蹤雙向檢測器 (Instagram Follower Inspector)

> **100% 純前端本地端運行、零伺服器上傳、專為 Instagram 官方匯出壓縮檔（`.zip`）打造的雙向追蹤關係分析與深度整理工作台。**

本專案採用純原生網頁技術（Vanilla HTML5 / CSS3 / ES6+ JavaScript）建構，不依賴任何前端框架或後端伺服器。您無需輸入 Instagram 帳號密碼，亦無需授權任何第三方 API，僅需載入由 Meta / Instagram 官方匯出的 `.zip` 備份壓縮檔，所有解壓縮、HTML/JSON 結構解析、交叉比對與分類標記皆在瀏覽器記憶體（RAM）與本地端儲存空間（`localStorage`）中獨立完成，從根本杜絕帳號遭官方風控鎖定或隱私外洩之風險。

## 核心特色與隱私安全承諾

1. **100% 本地端離線運算（Zero-Server Privacy）**
   - 透過瀏覽器端 `JSZip` 直接於記憶體內解壓縮 `.zip` 檔案，完全無後端 API、無資料庫、無追蹤碼，所有個人社交圖譜資料絕不離開您的裝置。
2. **雙向關係精準交叉比對**
   - 自動提取並正規化 `followers`（粉絲）與 `following`（追蹤中）名單，精準計算出五大核心群組：**總粉絲**、**追蹤中**、**你尚未追蹤（僅對方追你）**、**互追中（雙向追蹤）**、**對方未回追（僅你追蹤對方）**。
3. **相容 Instagram 歷年匯出格式（JSON 與 HTML 雙引擎）**
   - 支援新版 `string_list_data` / `title` 結構之 JSON 檔案，以及包含時間戳記與個人網址之舊版 HTML 匯出檔；內建智慧路徑過濾器，自動排除 `blocked_accounts`、`close_friends`、`pending_follow_requests` 等非目標檔案。
4. **四種分析視角與即時雙向互動圓餅圖**
   - 支援「全部資訊」、「三區模式」、「粉絲模式」、「追蹤模式」四種視角切換，搭配手寫 `requestAnimationFrame` 驅動之 SVG 動態圓餅圖（具備半途打斷無縫補間、雙向懸浮聚光燈連動與動態數值跳動）。
5. **深度分類整理工作台（Triage Workspace）**
   - 針對「你尚未追蹤」、「互追中」、「對方未回追」三大名單提供獨立整理空間，內建三種標籤維度（**決策導向**、**關係導向**、**自訂標籤**）、`Shift + 左鍵` 連續區間勾選與底部懸浮批次操作工具列。
6. **無感跨時期多帳號智慧記憶（MinHash + Jaccard 相似度匹配）**
   - 無需手動匯出或匯入設定檔。系統透過 32-bit FNV-1a 雜湊與 MinHash 特徵抽樣建立本地端帳號指紋，當同一個帳號事隔數月重新匯入最新 `.zip` 時，自動識別並繼承既有標籤；若對方追蹤狀態發生異動（例如退追或回追），「關係導向」標籤將自動跨區繼承，而「決策導向」與「自訂標籤」則自動重置為未分類以重新審視。

## 功能模組詳解

### 1. 匯入檔案與官方匯出圖文教學 (`#page-upload`)

- **左欄（10 步驟完整圖文指引）**：
  - 內建從「進入 Instagram 個人檔案選單」到「下載 `.zip` 壓縮檔」的 10 個標準步驟說明與對應截圖。
  - 點擊任一教學步驟截圖即可開啟全螢幕高清燈箱（Lightbox）檢視細節，點擊圖片以外任意區域或按下 `ESC` 鍵即可快速關閉。
  - 在關鍵步驟（步驟 6 至步驟 9）嵌入醒目提示：包含建議開啟「要求下載項目」分頁對照、將日期範圍設為「**不限時間**」、格式可選「**JSON（推薦）或 HTML**」，以及下載完成後**請勿解壓縮**。
- **右欄（拖曳上傳區与自動跳轉）**：
  - 嚴格驗證 `.zip` 副檔名；若誤傳資料夾或其他檔案格式，將透過底部雙色膠囊通知（Toast）即時提示錯誤。
  - 解壓縮與解析完成後，自動切換至「分析結果」頁面並同步啟用左側導覽列的「進一步整理」子選單。

### 2. 分析結果儀表板與互動圓餅圖 (`#page-analysis`)

分析頁面採用「一頁式免捲動（Full-Viewport Dashboard）」雙區佈局，上方為數據視覺化區，下方為虛擬分塊載入之帳號名單區：

#### 四種分析視角模式（Perspective Modes）
透過左上角膠囊切換器，可即時改變統計方塊與右側圓餅圖的觀測維度：

| 視角模式 | 啟用之統計方塊 | 右側圓餅圖顯示邏輯 |
| :--- | :--- | :--- |
| **全部資訊**（預設） | 5 張方塊全開 | **全域總覽**：可點擊任一統計方塊切換單一關係高亮，或顯示全站總接觸人數與三大區塊佔比 |
| **三區模式** | 僅啟用第 2 排 3 張交叉關係方塊 | **三區關係總覽**：聚焦於「你尚未追蹤」、「互追中」、「對方未回追」三者占總接觸人數之比例 |
| **粉絲模式** | 啟用「總粉絲」、「你尚未追蹤」、「互追中」 | **粉絲結構剖析**：以「總粉絲」為 100% 分母，剖析粉絲中「互追中」與「你尚未追蹤」之比例 |
| **追蹤模式** | 啟用「追蹤中」、「互追中」、「對方未回追」 | **追蹤結構剖析**：以「追蹤中」為 100% 分母，剖析追蹤名單中「互追中」與「對方未回追」之比例 |

#### SVG 動態圓餅圖與雙向聚光燈連動
- **差值權重動態分母插值（Delta-Weighted Angle Interpolation）**：
  - 當使用者快速連點切換視角或統計方塊時，每一幀 `requestAnimationFrame` 皆即時寫回當前弧段狀態（`currentSliceState`），新動畫會從被打斷當下的精確視覺角度無縫接續補間，絕不跳幀或閃爍。
- **雙向懸浮聚光燈（Bidirectional Spotlight）**：
  - 滑鼠懸浮於圓餅圖弧段或右側圖例列時，目標項目會放大亮起並維持 100% 不透明度，其餘非目標弧段與圖例則平滑降暗至 30% 不透明度。
- **單擊鎖定與雙擊直達整理工作台**：
  - **單擊**統計方塊或圓餅圖弧段／圖例：鎖定該分類並於下方名單區展開對應帳號列表；再次單擊同一項目即可取消選取並回到總覽狀態。
  - **雙擊**第 2 排任一關係方塊（「你尚未追蹤」、「互追中」、「對方未回追」）或對應圓餅圖弧段／圖例：直接跳轉至該分類專屬的「進一步整理」工作台。

#### 高效能虛擬分塊名單（Chunked Infinite Scroll）
- 支援即時關鍵字模糊搜尋（`@username`）、四種排序方式（時間最新／最舊、字母 A→Z／Z→A）與「單欄／多欄」檢視切換。
- 採用 `DocumentFragment` 每次動態渲染 120 筆資料，搭配捲動觸底自動續載，即使面對數萬名粉絲也能保持 60fps 流暢捲動。
- 整張帳號列皆為原生 `<a>` 連結卡片，支援滑鼠左鍵新分頁開啟與滑鼠中鍵背景開啟該使用者的 Instagram 個人主頁。

### 3. 進一步整理工作台與標籤系統 (`#page-triage-*`)

針對三大核心關係群組（「你尚未追蹤」、「互追中」、「對方未回追」）分別提供獨立的整理空間，協助使用者系統化盤點並管理帳號名單：

#### 三種標籤分類模式（Tag Modes）
每個整理空間皆可自由切換三種互不干擾的標籤模式：

1. **決策導向（Decision Mode，分區獨立）**
   - 依所在關係區域提供專屬行動標籤：
     - **你尚未追蹤**：`考慮回追`、`不回追`、`待觀察`、`移除粉絲`
     - **互追中**：`核心友列`、`一般認識`、`考慮退追`、`移除互動`
     - **對方未回追**：`退追名單`、`繼續追蹤`、`待觀察`、`官方/名人`
2. **關係導向（Relation Mode，跨區隨人轉移）**
   - 全域共用之身分屬性標籤：`摯友/重要`、`現實朋友`、`同學/同事`、`網友/同好`、`創作者/偶像`、`品牌/官方`、`小帳/分身`、`陌生帳號`。
3. **自訂標籤（Custom Mode，分區獨立）**
   - 使用者可輸入最多 14 字元的自訂標籤名稱，系統會從 10 色高對比霓虹色盤中自動循環分配專屬色彩。
   - 點擊自訂標籤膠囊右側的 `×` 可刪除該標籤；若該標籤已有標記帳號，將彈出確認視窗提示受影響人數。

#### 極速批次標記與鍵盤操作體驗
- **全列點擊勾選與帳號連結防誤觸分離**：點擊名條任意空白處即可切換勾選狀態；僅在精準點擊 `@username` 文字連結時才會開啟 Instagram 頁面。
- **`Shift + 左鍵` 區間連選**：勾選第一筆帳號後，按住 `Shift` 並點擊另一筆帳號，即可一鍵選取或取消兩者之間的所有名單。
- **底部懸浮批次工具列（Floating Batch Dock）**：一旦勾選任一帳號，畫面底部即滑出毛玻璃批次工具列，支援一鍵套用標籤、批次清除標籤或取消選取，並於完成後自動清空勾選狀態。

### 4. 靜默本地端多帳號智慧記憶引擎 (LRU Profile Cache)

本工具於 `js/triage.js` 內建全自動、零干擾的本地端快取機制（儲存鍵值：`ig_inspector_profiles_v1`）：

- **帳號指紋提取（Account Fingerprinting）**：
  - 匯入 `.zip` 時，系統將 `followers` 與 `following` 聯集正規化排序，並透過 **32-bit FNV-1a 雜湊演算法** 計算最多 2,500 筆最小雜湊特徵樣本（MinHash Sketch）。
- **跨時期自動匹配（Jaccard Similarity $\ge 0.40$）**：
  - 若為**完全相同**的 `.zip` 檔案（Hash 與人數完全一致），直接 100% 還原所有標籤。
  - 若為**同一帳號事隔數月後重新匯出**的新 `.zip`（追蹤名單已有增減），系統會比對本地快取中各設定檔的 **Jaccard 交集相似度** 與 **總人數比例**；當綜合相似度達 `0.40` 以上時，即判定為同一帳號並自動升級指紋與合併資料。
- **跨區狀態轉移邏輯**：
  - 當某位使用者從「互追中」變為「對方未回追」（對方退追你）時，該使用者的**「關係導向」標籤（例如：`同學/同事`）會自動跟隨帳號轉移至新分區**；而原本的**「決策導向」與「自訂標籤」則自動歸零為未分類**，提醒您針對其最新狀態重新做出決策。
- **50 組多帳號 LRU 容量管理**：
  - 支援在同一個瀏覽器中輪流分析最多 **50 個不同 Instagram 帳號**（例如主帳、小帳、社團帳、品牌帳），採用最近最少使用（Least Recently Used）策略自動維護儲存空間。

## UI / UX 視覺與幾何對齊規範

- **深色玻璃擬態介面（Dark Glassmorphism）**：以深邃藍黑（`#0b0f19` / `#131b2e`）為基底，搭配毛玻璃背景模糊（`backdrop-filter: blur(12px)`）與語意化高對比霓虹色票。
- **頂部與次級控制列 36px 絕對等高規範**：搜尋框、排序下拉選單、單多欄切換器、標籤模式切換器與自訂標籤輸入框，統一強制鎖定 `height: 36px` 與 `box-sizing: border-box`，實現像素級水平對齊。
- **全站零原生 Tooltip 干擾**：徹底移除所有 HTML `title` 屬性，避免滑鼠移動時產生瀏覽器原生黃色／白色小方塊遮擋視線。
- **純 SVG 向量圖示系統**：全站介面與文件嚴格遵循零 Emoji 規範，所有視覺引導、狀態指示與操作按鈕均採用精準繪製的內嵌 SVG 向量圖示。

## 快速開始與部署方式

### 方式一：本地端直接開啟（零安裝）
1. 下載或 Clone 本專案至您的電腦：
   ```bash
   git clone https://github.com/<your-username>/InstagramFollowerInspector.git
   ```
2. 直接使用現代瀏覽器（Chrome、Edge、Brave、Firefox、Safari）雙擊開啟資料夾內的 `index.html` 即可立即使用。

### 方式二：使用本地開發伺服器（VS Code Live Server / Python / Node）
若您正在進行二次開發或樣式調整，可使用任意靜態伺服器啟動：
```bash
# 使用 Python 3 內建伺服器
python -m http.server 8080

# 或使用 Node.js serve
npx serve .
```
接著於瀏覽器造訪 `http://localhost:8080`。

### 方式三：部署至 GitHub Pages / Vercel / Netlify
本專案為純靜態網頁結構，無需任何建置指令（Build Command 留空，Output Directory 設為根目錄 `/`），推上 GitHub 儲存庫後即可於 **Settings > Pages** 一鍵啟用 GitHub Pages 免費代管。

## 常見問題與已知官方資料限制

1. **為什麼工具上的粉絲／追蹤人數與 Instagram App 內顯示的數字差幾個人？**
   - Instagram 官方產出的匯出壓縮檔屬於「靜態時間點快照」，且常包含**已停用（Deactivated）、已封鎖或遭官方刪除的幽靈帳號**，而 App 端則有快取延遲與不同的過濾計算方式，因此存在個位數至十位數的微小落差屬於正常現象。
2. **為什麼顯示「對方未回追」，但我點進他的主頁卻發現他其實有追蹤我？**
   - 這是 Meta 官方匯出系統的已知問題：在極少數情況下，官方產出的 `followers` 檔案會漏列部分近期粉絲。建議在決定退追前，直接點擊名單列前往對方的 Instagram 主頁做最終確認。
3. **整理到一半關閉分頁，標籤紀錄會消失嗎？**
   - 不會。每一次點擊標記或批次操作都會即時寫入瀏覽器的 `localStorage`。只要未清除瀏覽器網站資料（或使用無痕視窗關閉後重開），下次載入同一個帳號的 `.zip` 時便會自動無感還原所有分類進度。
